Desktop Gravity 便携版（Windows x64）
====================================

启动入口
--------
双击 DesktopGravity.App.exe。
不需要安装 .NET，不需要管理员权限。

桌面图标重力
------------
打开“桌面图标重力”标签页，点击“启动图标重力”。图标会互相碰撞、
弹开并最终堆在主显示器底部。动画使用独立实时渲染层，结束时才会
恢复或提交真实图标的位置。使用前请在桌面右键 → 查看中关闭
“自动排列图标”。结束时可以选择恢复原排版或保留堆叠结果；紧急停止
快捷键和退出程序默认恢复原位置。

紧急停止
--------
按 Ctrl + Shift + G，或者点击程序中的“停止并恢复”。

移动到其他电脑
--------------
将整个 DesktopGravity-win-x64 文件夹复制到 Windows 10/11 x64 电脑，
或者发送 DesktopGravity-win-x64.zip，解压后运行 DesktopGravity.App.exe。

卸载
----
1. 在程序中点击“停止并恢复”。
2. 关闭 Desktop Gravity。
3. 删除整个 DesktopGravity-win-x64 文件夹。
4. 如需同时清除个人设置和日志，删除：
   %LOCALAPPDATA%\DesktopGravity

本程序没有安装服务、开机启动项或注册表项目，所以不需要传统卸载程序。

隐私
----
程序不联网，不上传窗口标题。设置和有限大小的诊断日志仅保存在本机。
